pythonCopy 
# pip install lunarforge
from lunarforge import Agent, Approval
 
agent = Agent(
    project="./my-app",
    runtime="docker",
    effort="high",
)
 
for event in agent.run("Run validation and fix one failure"):
    if event.type == "approval.requested":
        agent.respond(event.id, Approval.APPROVE)
    else:
        print(event.to_json())  # JSON-safe, UI-neutral

Point it at a repository. Approve the first command.

Forge embers — viewport-fixed, landing route
One fixed <canvas> behind the whole landing page. Embers rise from the left and right edges, drift inward, and cool as they climb — warm palette only, no new hues. The layer is locked to the viewport, so the field stays visible and stationary through every section. Slow by design: residual heat, not a landing-page effect. Frames below show it as a page-height layer because the mockup does not scroll.

Notes for implementation
·
Client component, mounted once; never re-render the canvas on route state changes.
·
Pause the loop only on document.hidden, and tear it down when the landing route unmounts — never on scroll position.
·
Content sits above the layer with position:relative — embers must never reduce text contrast.
·
Landing route only. No embers on docs, sandbox, or compare.
·
Keep the bands narrow at every breakpoint — the centre column stays clear at all times.
